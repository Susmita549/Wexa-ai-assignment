# JobGraph Cypher Queries

Reference queries for the JobGraph application. All queries use parameterized placeholders.

| File | Use case |
|---|---|
| `jobs-by-skills.cypher` | Direct skill-based job recommendations |
| `indirect-job-recommendations.cypher` | Multi-hop job discovery via project technologies |
| `shortest-path-developer-job.cypher` | Relationship path exploration |
| `technologies-by-skill.cypher` | Technology discovery from a skill |
| `developer-projects.cypher` | Project discovery for a developer |
| `company-jobs.cypher` | Company and job exploration |

See also: `../schema/use-case-queries.cypher` for validation query templates.
